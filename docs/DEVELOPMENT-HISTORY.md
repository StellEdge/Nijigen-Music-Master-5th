# 歌牌播放器

参考本项目 `Nijigen Music Master` Unity 工程，在独立目录中重写的歌牌自动播放器。原工程和 MusicData 均未修改。

## 启动

直接双击 **index.html**，使用现代 Chrome、Edge、Firefox 或 Safari 打开。无需 Unity、安装依赖、构建、联网或账号。也可在本目录执行 `python -m http.server 8765 --bind 127.0.0.1`，打开 `http://127.0.0.1:8765`。`npm start` 是同一命令的快捷入口，需 Python。

Windows / macOS / Linux 使用浏览器运行同一份代码。Android / iOS 建议通过静态网页服务打开页面，并在文件选择器导入 ZIP；移动系统打开本地 HTML、文件夹选择及全屏的能力因浏览器而异。页面自适应手机屏幕。首次读牌必须手动点击；若手机浏览器阻止异步音频播放，点击重播。移动端锁屏、切换应用或浏览器休眠可能暂停音频或延迟切牌，比赛时请保持页面前台和屏幕常亮。

## 加载现有歌包

点击「选择 ZIP 曲包」或拖入 ZIP 文件导入，可一次选择多个 ZIP。不支持直接导入文件夹、CSV、音频或图片等散文件；请先将完整歌包压缩为 ZIP。

ZIP 可以包含一个或多个歌包，每个包含自己的 `data.csv`，允许嵌套目录。支持常见 Store / Deflate ZIP、UTF-8 / GB18030 文件名和 Info-ZIP Unicode 文件名。不支持加密、分卷、ZIP64，单文件解压限 512 MiB；遇到不支持的 ZIP 请重新打包为普通 Store / Deflate ZIP。ZIP 在浏览器内解压，不上传；单首音频和图片按需提取，而非一次解码全部歌曲。

CSV 与 Unity 工程兼容，字段可重排，至少提供 `title,music`，其余可留空：

当前仓库 Dark 歌包第 28 首引用的 `028-寄生兽-生命的准则.jpg` 不存在，导入时会提示一次图片缺失；全部 50 首音频仍可加载。CoreSet 为 2 首，共 52 首。

```csv
No,title,subtitle,artist,translated,animation,music,image
1,鳥の詩,,Lia,鸟之诗,Air,001-Lia (りあ) - 鳥の詩 (鸟之诗).flac,001-鸟之诗.png
2,Crossing field,,,,刀剑神域,015-刀剑神域Crossing field.mp3,
```

文件路径相对于 CSV 所在目录，支持子目录及 Windows 反斜线。CSV 默认严格 UTF-8 解码，失败后回退 GB18030；可手选编码后重新导入。支持 BOM、带逗号/换行的引号字段和双引号转义。精确文件名优先，大小写回退仅在路径唯一时使用。缺失图片仍可播放；缺失音频跳过该行，诊断显示原因。同名歌不冲突。重复导入会作为独立歌包加入，可以用 × 移除。

浏览器原生解码 MP3、WAV、FLAC、OGG、M4A 等格式，实际可用格式以浏览器及系统解码能力为准。不内置 FFmpeg 或全量音频解码器。图片通过浏览器原生显示，使用 cover 等比放大并居中裁剪，填满卡面。

## 播放与游戏

播放器铺满窗口，左上角只显示五周年 LOGO，不另放 BY 星刃文字。右上角为加载曲包、播放列表、读牌设置三个悬浮菜单。横屏（至少 600px 宽）左侧大歌牌、右侧歌曲信息与控制；竖屏上下排列。所有边缘操作区计入 `safe-area-inset-*`，为刘海、圆角与底部手势区留边。设置或列表过长时只在菜单内滚动。

### 普通音乐模式

未点击「开一局」时，行为与普通播放器一致：点击歌曲或 ▶ 播放整首，显示歌名、图片与时长；可暂停、继续、上下首、拖动整首进度和调节音量。整首播放完自动接下一首，不使用游戏片段长度、固定/随机起点、牌间间隔、TVSize、全自动与揭晓规则，也不新增对局记录。播放图标随状态切换为暂停符号。选择歌曲后自动收起列表。

### 游戏控制

独立矩形包含「开一局 / 结束」「播放热场音乐」「随机 / 顺序」「全自动」「TVSize」「揭晓」。点击「开一局」按勾选曲目创建本局，按钮变为红色「结束」，矩形边框持续流动高亮；暂停和热场期间仍属游戏中。点击「结束」停止并退出游戏，回到普通模式；不开启循环时，本轮读完也回到普通模式。重播键已移除。

- 随机 / 顺序只决定新一局的牌序，播放中切换不会改变本局。Fisher-Yates 洗牌优先使用 Web Crypto；同轮不重复，独立局之间允许同一首歌再次成为首曲。
- 全自动开启后，默认每首片段 30 秒，结束后进入牌间间隔再切歌。片段长度、起点、间隔和整轮循环可在设置调整；关闭全自动后，片段结束等待手动下一首。片段长度 0 为从固定起点播到结尾，不使用随机起点。
- TVSize 为随机起点限制：开启随机起播时，将起点限制在 0～80 秒；短曲受有效时长进一步限制。该键不把片段长度改成 90 秒。
- 揭晓开启时，游戏播放初段隐藏歌名和图片，最后 3 秒和牌间空歇显示；短片段只在最后三分之一显示。下一张重新隐藏，结束游戏后恢复普通显示。此功能用于自我练习，导入诊断和导出记录仍可包含答案。
- 歌包和曲目勾选决定新局范围；搜索只筛选显示。游戏中点击列表内本局曲目可跳转，不重开一局。

### 热场音乐

点击「播放热场音乐」独立循环播放整首热场音频；再次点击以约 3 秒淡出结束，淡出期间继续显示热场曲名；切换其他歌曲时立即停止热场。优先使用本页面中手动指定的文件，未配置时使用内置的 `assets/GRAND CARD TOUR -The Fifth Anniversary Anthem-.mp3`，无需导入歌包。在设置中可更换音频或点击「恢复默认音乐」；播放中恢复会立即切换为默认曲继续循环，停止时恢复则不自动播放。普通播放或游戏均可热场：它暂停原音频或倒计时，不自动开局、不改变本局牌序、不新增记录。播放任何其他歌曲时停止热场并熄灭热场按钮，手动停止后点击 ▶ 继续原播放。结束游戏同时停止热场。

### 设置与快捷键

模式开关保存至浏览器本地偏好；音频和歌包不写入数据库，刷新后需重新导入。对局记录可导出 JSON，不含音频图片。设置中保留片段长度、间隔、固定/随机起点、循环、热场音频和记录，不重复主面板开关。

快捷键（焦点不在输入控件时）：Space 播放 / 暂停，← / → 上下首，A 切换揭晓设置。

音乐片段约 0.45 秒淡入、0.65 秒淡出，短片段按比例缩短。普通播放和热场按整首起止淡入淡出，音量与 GainNode 包络相乘。手动暂停、切歌与结束即时响应。播放错误停在当前首，显示原因，可切换歌曲或重新点选重试。

## 与 Unity 工程对应

| 原工程 | 新实现 |
|---|---|
| MusicData 的八列元信息 | 保留并展示标题、副标题、歌手、译名、作品、音频及图片 |
| MusicLoader 读取子目录 data.csv | ZIP 多包加载，去掉硬编码路径和 Dark 包过滤 |
| MusicWheelItem / SongListScrollbar | 可滚动、可搜索和可勾选的曲目列表，点击切歌及图片展示 |
| MusicPlayer 播放 / 暂停 / 续播 | 浏览器原生音频、音量、进度和完整状态控制 |
| 启动随机排列 | Fisher-Yates 不重复牌序，可选顺序播放 |
| ProgressIcon / MusicWheel 等空实现 | 音频进度、轮次进度和倒计时 |
| 尚未实现的自动播放流程 | 片段、间隔、自动下一张、循环、练习揭晓、记录导出 |

新版本不复刻 Unity 3D 物体或依赖 NAudio，采用纯 HTML/CSS/JavaScript，无第三方运行依赖、遥测或外部字体。

## 验证与目录

`node --test tests/core.test.cjs`：CSV、路径安全、真实歌包资源引用、重复歌名、GBK、随机牌序、片段边界及 ZIP 校验测试。真实歌包测试依赖上级目录的 MusicData。浏览器回归测试脚本 `tests/browser.cjs` 需要外部 Playwright（不属于运行依赖），通过 `PLAYWRIGHT_PATH` 指定模块路径。

- `core.js`：数据格式、片段计算、随机牌序
- `zip.js`：ZIP 索引、按需解压及 CRC 校验
- `app.js`：导入、播放状态、会话和界面
- `index.html` / `style.css`：无框架响应式界面

发布时只需分发前述五个文件与 assets 文件夹（或包含本说明的完整文件夹），歌包独立分发。也可放在任意静态网页服务上，无需后端。文件内容只在设备内处理。

## 视觉样式

浅蓝、薄荷绿、淡紫与暖桃色的明亮配色，使用清透面板、细描边和平整按钮；底部进度与全部播放控制合并为一个整体悬浮面板。歌牌按图片原始比例显示，白色卡边、轻微倾斜与分层投影模拟实体牌悬置。无图片、图片加载失败及盲听隐藏封面时显示 `assets/cardback.png` 五周年卡背，图片采用等比放大、居中裁剪填满卡面。主播放器仍铺满窗口且无需页面滚动。

切换下一张时，新牌从右侧滑入、旧牌向左滑出；上一张则反向切换，伴随轻微旋转和落位。动画不阻塞音频加载，连续切换会清理旧动画和临时卡牌。背景由四个半透明光斑缓慢随机漂移，页面隐藏时暂停，恢复可见后继续。系统开启「减少动态效果」后取消背景动效，切牌即时完成。全部效果使用 CSS / 浏览器原生动画，无外部动画依赖。

## 图标与音频频谱

主菜单与游戏控制使用内置 SVG 图标，悬停可查看功能，按钮保留屏幕阅读器名称和按下状态。右上角无按钮底框与可见状态标签；音量不显示文字，使用浅色滑轨。

播放时通过 Web Audio AnalyserNode 获取实际输出频谱：普通播放和热场共用分析节点，位于增益之后；频谱按中心左右镜像，以半透明灰色圆角柱绘制在歌牌、面板下方；柱数随屏宽增加，约每 12px 一柱，保持视觉密度。暂停、结束或页面隐藏时清除并停止绘制，重新播放后恢复；静音和静音音频不会生成伪造跳动。画布像素比最多 1.5，绘制约 30 帧 / 秒，无外部依赖。

背景光斑每段随机漂移约 5.5～9.5 秒，比此前更明显。系统开启减少动态效果时停用光斑和频谱动画。

游戏控制为六个圆形图标按钮，整齐排列在同一行。播放列表新增「按歌包选择」：整包勾选 / 取消，与单曲勾选同步；部分选中时歌包复选框显示中间状态，并显示已选 / 总数。歌包选择作用于新局，不更改正在进行的牌序。

右上角三个菜单图标在所有尺寸中保持顶端同一行；窄屏缩放左侧 LOGO，不把菜单推到下一行。

歌牌最大显示尺寸缩小为原先的 90%，持续以 24 秒为一周期轻微左右摇晃（约 ±7px 位移、±0.65° 摆角）。摇晃与切牌动画使用独立变换属性；系统减少动态效果时关闭。

频谱定位：竖屏在歌曲信息上方的窄带内绘制，最大高度为屏幕高度的 9%（最多 100px）；横屏固定在屏幕高度约 67%～83% 的背景带，最大高度为屏幕高度的 16%，并避开底部安全区，不再跟随控制台底边。位置由实际信息区 / 控制区布局计算，随窗口与内容尺寸更新，所有柱子的高度严格限制在该带内。

## Android 试用 APK

已生成 `dist/NijigenMusicMaster-1.0.0-preview3.apk`，约 9.6 MB，Android 8.0+，使用系统 WebView，内置五周年应用图标、播放器、卡背和默认热场音乐。将文件传到手机后直接安装；曲包通过系统选择器导入 ZIP。原生源码、离线构建脚本与验证范围见 `android/README.md`。本轮未在真机或模拟器安装启动验证。

Android preview.2：应用名称「歌牌播放器」，包名 `com.stelledge.nijigenmusicmaster`，使用 app-icon-5th-v2.png，并内置已替换的新周年热场音频。

Android preview.3 支持记住导入 ZIP 的系统文档引用与读取授权，下次自动恢复曲包；不复制整包。升级后首次需重新导入以建立记忆。文件移动、删除或授权失效时提示重选。普通网页仍受浏览器文件授权限制，不保证刷新后自动恢复。顶部渐变与 Android 状态栏同色衔接。

页面布局修正（尚未打入 APK）：横屏控制台靠右下角，长标题限制在右栏内；LOGO 与菜单图标使用相同的 44px 高度与顶边。播放进度条、音量条使用可收缩网格并清除原生外边距；六个模式按钮改为显式 flex 居中。触摸点击后清除临时按钮焦点，参数颜色仅由 aria-pressed 决定，键盘焦点提示保留。
