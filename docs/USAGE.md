# 使用指南

## 歌包格式

通过「选择 ZIP 曲包」或拖放导入，可一次选择多个 ZIP。不支持直接导入文件夹或散文件。ZIP 内每个歌包以自己的 `data.csv` 为入口：

```text
my-pack.zip
└── MyPack/
    ├── data.csv
    ├── song.wav
    └── cover.png
```

```csv
No,title,subtitle,artist,translated,animation,music,image
1,示例歌曲,,示例歌手,,示例作品,song.wav,cover.png
```

至少提供 `title,music` 两列；路径相对于 CSV，允许子目录与反斜线，不允许绝对路径和 `..`。支持 BOM、引号、逗号和多行字段。编码默认 UTF-8，失败后回退 GB18030，也可手动选择编码后重新导入。

缺少图片时显示卡背，缺少音频时跳过该行并显示诊断。支持 Store / Deflate、常见 UTF-8 / GB18030 文件名；不支持加密、分卷和 ZIP64。单文件解压不超过 512 MiB。导入过程在本机完成。

仓库 `tests/fixtures/test.zip` 是合成音频测试包，可用于体验导入，不是商业曲库。

## 普通播放与游戏

未开局时，点击歌曲或播放键播放整首，不使用游戏片段或揭晓规则，整首结束自动下一首。

勾选歌包或曲目后点击「开一局」。随机 / 顺序只影响新一局的牌序，搜索只影响显示。全自动按设定片段和间隔切歌；关闭后等待手动下一首。片段长度为 0 时从固定起点播到结尾。

TVSize 只限制随机起点至 0～80 秒；短歌进一步限制范围。揭晓模式在片段初段隐藏答案，最后 3 秒显示；短片段在最后三分之一显示，牌间间隔保留答案。结束游戏恢复普通模式。

热场按钮独立循环播放设置中选定的音频，未设置时使用内置周年音乐；再次点击约 3 秒淡出。热场暂停原播放或游戏倒计时，不新增记录。停止后点击播放继续原内容。

## 保存与快捷键

模式偏好保存在本机浏览器；普通网页刷新后需重新导入曲包。Android 使用系统文档授权记住 ZIP 引用，文件移动或授权失效后需重选。记录可导出 JSON，不含音频和图片。

输入控件之外：Space 播放 / 暂停，左右方向键切歌，A 切换揭晓。移动浏览器首次播放需要手动操作；比赛时保持网页前台和屏幕常亮。

连续点击 LOGO 五次可触发周年彩蛋，分三轮触发，第三轮会启动热场音乐。完整历史交互说明见 [开发历史](DEVELOPMENT-HISTORY.md)，其中旧版本描述不作为当前功能承诺。
